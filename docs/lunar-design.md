# Lunar portfolio

A store owner opens the portfolio in a browser to assess a real person and their work; the dark lunar backdrop creates a quiet observatory while bright text keeps the business information readable.

Restrained monochrome, drawing from BreakFree's OLED moon scene. Manrope for interface and body; Instrument Serif italic for the hero's personal promise. Fine orbital lines, one modeled lunar sphere, generous section spacing, and project-specific illustrations instead of invented product screenshots.

Motion personality: cinematic and restrained. Native page scroll. Hero entry within 720 ms; section entry 600 ms with 80 ms stagger; hover 220 ms. Three easing tokens. Slow lunar rotation and orbit with pointer tilt. Scene pauses outside the viewport, when the document is hidden, and on request. Reduced motion renders a static scene and removes translation, rotation, and scrolling effects.

Semantic HTML is independent of the lazy-loaded WebGL scene. A CSS textured sphere remains available if WebGL or the scene fails. Project details use native dialogs with focus restoration; service details use native disclosure elements.

The prior city experiment remains at /v2.html.
